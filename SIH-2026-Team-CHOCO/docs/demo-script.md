**Action on screen:** Briefly show terminal logs of the ML server processing the request, then switch to a slide showing the Transformer/GNN diagrams.

It took our system 3 seconds to do what takes human investigators 3 weeks."

### [1:45 - 3:00] Member 3: Command Center & Real-time Action
**Action on screen:** Open Command Center. Show the Leaflet Heatmap updating live. Click the ATM marker. Show the vis.js Graph. Type a query into the LLM Agent.

If the inspector wants more intel, they don't need to know SQL or Cypher. They just ask our LLM Agent: *'Show me all mule accounts linked to this case.'* The AI queries the graph and returns the data.

## Anticipated Q&A (Be Ready!)
1. **"What if the criminal uses a bank transfer instead of an ATM?"**
   *Answer (M1):* The GNN still flags the destination mule accounts, allowing the inspector to freeze the accounts directly via the Action Panel.
2. **"How do you handle privacy and PII?"**
   *Answer (M2):* All PII is kept in PostgreSQL with strict RBAC (Role-Based Access Control). The ML models and Neo4j graph only operate on anonymized IDs.
3. **"Is this actually scalable to a country like India?"**
   *Answer (M3):* Yes. Our stateless microservices scale horizontally on Kubernetes, and Neo4j handles highly connected graphs efficiently up to billions of nodes.
